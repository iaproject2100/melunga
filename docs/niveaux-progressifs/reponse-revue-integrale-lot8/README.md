Les motifs restent contextuels : No hay que peut exprimer une absence de
nécessité ou une recommandation négative selon le contexte ; Flipas peut
recevoir une traduction pragmatique au futur ; très et trop peuvent varier
avec la situation. Les après retenus servent les sens visés ici, sans faire
de chaque traduction antérieure une faute universelle.

Pour EN71 (2205), l’épellation formelle E + N contient /e e.ne/. L’après
« é-né » peut se défendre par coalescence orale [e.ne], tout en étant
indiscernable de N prononcé seul. Cet événement source est conservé sans
nouvelle chaîne inventée ; sa segmentation est à confirmer avec Claude.
Ce point ne fixe aucune convention générale d’épellation.
