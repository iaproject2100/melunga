## Limites maintenues

La densité d’un thème ne prouve pas sa progressivité. Le seuil compte les concepts explicitement liés ; pour les autres entrées, une identité study/native n’est pas un test complet de synonymie. Les 30 889 niveaux source non relus individuellement et les prérequis non clos sont signalés dans le compte rendu général.

Les 32 115 sources et les aides anciennes restent entières et inchangées. Les banques de révision sont des copies de transport identifiées referenceOnly, sans nouvelle identité canonique. Aucun prix, droit gratuit ou abonnement n’est modifié. Aucun accord de publication n’est déduit de ce dossier.
