# Rubriques longues : état de l’application

**67 rubriques dépassent 100 présentations**, révisions comprises. Elles ne sont pas découpées en séquences visibles. Les groupes techniques de cinq cartes sont aplatis en une seule leçon par `openTheme()` ; leur existence dans les JSON ne constitue pas une pause d’apprentissage.

Le démarrage d’un thème reste à un clic. Cette composition ne crée pas d’écran intermédiaire de choix des séquences. Pour donner de vraies étapes aux rubriques de plus de 100 présentations, il faudrait traiter les 67 rubriques listées dans le JSON. Aucun découpage supplémentaire n’est appliqué ici.
