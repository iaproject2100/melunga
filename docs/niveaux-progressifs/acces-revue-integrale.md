L’accès brut GitHub au manifeste a répondu HTTP 200 sans authentification. Le navigateur hébergé n’a pas été testé depuis cet environnement : son proxy refuse Netlify. Si l’environnement de Claude rencontre le même blocage réseau, les liens GitHub bruts et le dépôt permettent la revue complète ; un lien Netlify ne peut pas supprimer ce blocage. Aucun secret ou compte partagé n’est nécessaire.

## Périmètre à couvrir sans omission

- **33 654 cartes canoniques** : 32 115 historiques et 1 539 enrichissements/imports ; **32 792 visibles et 862 en réserve**.
- **252 modèles reçus**, dont 32 partagent exactement l’identifiant d’une carte ; **220 identifiants supplémentaires**, soit **33 874 identifiants de contenu distincts** au total.
- **259 usages reçus**, à vérifier dans leurs situations ; 1 636 thèmes et 70 cellules langue/niveau.

Lire les 70 JSON ci-dessous, `themes[].phrases` **et** `reserve[]`. Lire aussi `receivedModels` des sept répertoires et leurs usages dans les étapes `receive`. L’interface ne présente pas les 862 réserves. Les seuls `repertoires[].phrases` ne constituent pas le catalogue complet : ils ne contiennent que 2 021 copies de transport. Ne pas compter ces copies comme des créations supplémentaires.

La référence de départ est figée à `4ec163e`. Les corrections se font sur une branche de revue ; les liens figés permettent de comparer avant/après.
