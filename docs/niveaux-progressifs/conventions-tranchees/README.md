# Conventions espagnoles et coréennes — livraison de revue

Cette branche dépend de la PR de contenu #16, commit d’entrée `e85c8c355be8cc0213543eddb21467432edb57b8`. Les blocs de contenu sont appliqués avant les aides `afterContentRegister`. Elle ne contient pas le nouveau classement de la PR #17.

Les registres de `68031b7`, l’erratum de contenu `4247ca4` et les cinq corrections coréennes de `d5ad5e4` sont conservés comme preuves entières. Aucun convertisseur phonétique n’est exécuté sur le reste du corpus.

Résultat : **2 100 identités, 2 167 objets avec copies et modèles reçus, 2 122 références de preuve**. Les 21 suites après contenu sont confrontées aux blocs exacts avant application. Les cinq aides de l’erratum remplacent seulement leurs après livrés : `kkon-nip`, `al-lyak` et les trois aides entières avec `keun-nil`.

Les trois conventions devenues sans objet pour es:3353, ko:3767 et ko:3637 ne réécrivent pas les blocs corrigés. Les 69 situations exclues restent hors de ce raccord ; elles ne sont pas réputées traitées. Le contrôle protège ces 72 identités et leurs 78 objets.

Le générateur refuse les avant inexacts, les copies périmées, les annotations manquantes et les blocs partiels. Le contrôle indépendant reconstruit toute l’édition depuis les preuves, contrôle les cinq corrections officielles puis fournit une projection privée vérifiée vers le contenu B et l’édition historique. Il rejette 45 altérations ciblées, sans importer le producteur.

Les nouveaux essais navigateur portent sur l’édition actuelle : les 21 suites, les cinq aides corrigées, les recouvrements protégés, les modèles reçus et les aides les plus longues de chaque niveau concerné. Les anciennes étapes vérifiées ne sont accessibles aux tests historiques qu’après contrôle de l’édition réelle.

La présentation, les prix, les droits, les abonnements, les niveaux source et les 32 115 cartes classiques restent inchangés. Les contrôles locaux utilisent des écrans simulés et une synthèse vocale instrumentée ; ils ne certifient pas une écoute native ni un essai sur téléphone physique. Aucune fusion dans `main` ni publication sur melunga.com n’est autorisée.
