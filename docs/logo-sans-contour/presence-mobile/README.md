# Marque plus visible sur mobile

Le logo est affiché dans un carré de 64 px sur mobile. Avec le masque existant, son disque visible mesure 55,04 px, contre 44 px pour les pastilles. Le nom Melunga passe à 30 px, ou 28 px sous 340 px de largeur. La mascotte originale, son masque sans contour et toute la présentation desktop sont conservés.

Le produit ne change que quatre groupes de dimensions dans les règles mobiles et les caches CSS v24 des deux entrées. PNG, JS, cartes, progression, droits et prix sont inchangés depuis `40f671a`.

Les quatre groupes existants du logo passent : 13 cas, géométrie mobile 320/390/461/640 px, thèmes/leçons, PNG/masque exacts, bureau identique au main précédent, commandes Pinyin/niveaux/menu. Le disque du logo reste plus grand que chaque pastille et aucun élément de marque ou bouton n'est coupé.

Les contrôles existants source+titre ont aussi été exécutés pour vérifier l'espace laissé aux fiches longues : 44 cas conformes en français/chinois, trois ambiances et Pinyin, avec les petits écrans et la fenêtre basse. Ce second rapport est explicitement ciblé ; il ne revendique pas les cinq autres groupes de cette suite. Les empreintes courantes sont actualisées, sans modification des couches historiques.

Il s'agit de rendus locaux Chromium avec tailles d'écran simulées ; aucun téléphone physique, compte réel, audio ou achat réel n'est revendiqué.
