# Choix des langues — capsule verte « Voir un exemple »

Affinement demandé de la dernière image : c’est la page de choix des langues sur ordinateur qui reçoit la capsule verte « Voir un exemple », sous la grille. Un clic sur une langue ouvre directement la première fiche, sans bouton « Démarrer ».

Le prototype copie le véritable bouton d’exemple de l’accueil, avec ses styles et sa destination existante vers la démonstration. Il s’ajoute seulement dans le navigateur pour les captures ; aucun fichier produit n’importe ce dossier. Le parcours d’accueil reste intact.

- [Maquette ordinateur — 1366 × 768](choix-langues-exemple-vert.png)
- [Maquette grand écran — 1920 × 1080](choix-langues-exemple-vert-large.png)

Les vérifications utilisent les pages et contenus réels avec des réponses locales explicites pour les API. Aucun appareil physique, Safari, compte ou paiement réel n’est utilisé. Ce dossier propose un aperçu, sans fusion ni déploiement de production.
