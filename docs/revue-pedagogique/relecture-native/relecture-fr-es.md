# Melunga — revisión nativa, primera lección de español

Esta es la primera lección de una aplicación de idiomas. El alumno es un francófono principiante absoluto en español. Todo lo que sigue ya existe en la aplicación; solo necesitamos saber si te suena bien. Una línea por respuesta basta — cinco o diez minutos.

## La escena

| | | guía de pronunciación para lectores franceses |
|---|---|---|
| **EL ALUMNO DICE** | ¡Hola! | `O-la` |
| **EL CAMARERO DICE** | Hola. ¿Qué desea? | `O-la. ké dé-SSÉ-a` |
| **EL ALUMNO DICE** | Un café, por favor. | `oun ka-FÉ, por fa-BOR` |
| **EL CAMARERO DICE** | ¿Con leche? | `kon LÉ-tché` |
| **EL ALUMNO DICE** | No, gracias. | `no, GRA-ssias.` |
| **EL ALUMNO DICE** | ¿Cuánto cuesta? | `KOUAN-to KOUÉS-ta` |
| **EL CAMARERO DICE** | Dos euros. | `dos É-ou-ros` |

---

**1.** ¿Suena como un café real en tu país? Si no, ¿qué falla?

> 

**2.** El alumno saluda primero con « ¡Hola! ». ¿Natural para un cliente que entra?

> 

**3.** « Un café, por favor. » — ¿es así como pedirías? Si no, ¿qué dirías?

> 

**4.** **La pregunta clave.** « No, gracias. » aparece solo, como respuesta completa a « ¿Con leche? ». Aislado, ¿sigue sonando educado, no seco?

> 

**5.** « ¿Cuánto cuesta? » se dice después, como frase aparte. ¿Natural justo después de rechazar?

> 

**6.** Las frases del camarero son « Hola. ¿Qué desea? », « ¿Con leche? », « Dos euros. ». ¿Las diría de verdad?

> 

**7.** ¿Algo que suene anticuado, regional, o que simplemente nunca dirías?

> 

**8.** Opcional, solo si lees francés: un francófono lee « oun ka-FÉ, por fa-BOR » en voz alta para aproximar « Un café, por favor. ». ¿Se acerca?

>
