# Melunga — ネイティブチェック、日本語の第一課

語学アプリの一番最初のレッスンです。学習者は日本語をまったく知らないフランス語話者です。以下はすでにアプリに入っている内容で、自然に聞こえるかどうかだけ教えてください。各問一行で結構です。五分から十分で終わります。

## 場面

| | | フランス語話者向けの発音の目安 |
|---|---|---|
| **学習者のセリフ** | こんにちは！ | `kon-ni-tchi-wa` |
| **店員のセリフ** | こんにちは。ご注文は？ | `kon-ni-tchi-wa. go-tchou-ou-mon wa` |
| **学習者のセリフ** | コーヒーをお願いします。 | `ko-o-hi-i o o-né-ga-i chi-ma-sou` |
| **店員のセリフ** | ミルクは？ | `mi-rou-kou wa` |
| **学習者のセリフ** | いいえ、結構です。 | `i-i-é, kek-ko-o dé-sou.` |
| **学習者のセリフ** | いくらですか。 | `i-kou-ra dé-sou ka` |
| **店員のセリフ** | 三百円です。 | `san-bya-kou én dé-sou` |

---

**1.** 全体として本物のカフェのやりとりに聞こえますか。違和感があればどこですか。

> 

**2.** 学習者がまず「こんにちは！」と言います。入ってきた客として自然ですか。

> 

**3.** 「コーヒーをお願いします。」——この言い方で注文しますか。しないなら何と言いますか。

> 

**4.** **一番重要な質問です。** 「いいえ、結構です。」が単独で、「ミルクは？」への完全な返事として出てきます。単独でも丁寧に聞こえますか。そっけなくなりませんか。

> 

**5.** そのあと「いくらですか。」を別の文として言います。断った直後に自然ですか。

> 

**6.** 店員のセリフは「こんにちは。ご注文は？」「ミルクは？」「三百円です。」です。店員は実際にこう言いますか。

> 

**7.** 古い、地域的、あるいは自分なら絶対言わない表現はありますか。

> 

**8.** 特に「結構です。」について教えてください。ミルクを断る返事として、丁寧に響きますか。それともきつく聞こえますか。「いいえ、大丈夫です。」のほうが自然でしょうか。

> 

**9.** 任意です。フランス語が読める場合のみ：フランス語話者は「コーヒーをお願いします。」に近づけるために「ko-o-hi-i o o-né-ga-i chi-ma-sou」と読みます。近いですか。
