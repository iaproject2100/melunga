# Melunga — 원어민 검토, 한국어 첫 수업

언어 학습 앱의 가장 첫 수업입니다. 학습자는 한국어를 전혀 모르는 프랑스어 사용자입니다. 아래 내용은 이미 앱에 들어 있으며, 자연스럽게 들리는지만 알려 주시면 됩니다. 한 줄씩 답해 주세요. 오 분에서 십 분이면 충분합니다.

## 상황

| | | 프랑스어 독자를 위한 발음 근사 |
|---|---|---|
| **학습자가 하는 말** | 안녕하세요! | `an-nyeong-ha-sé-yo` |
| **직원이 하는 말** | 안녕하세요. 뭐 드릴까요? | `an-nyeong-ha-sé-yo. mwo deu-ril-kka-yo` |
| **학습자가 하는 말** | 커피 하나 주세요. | `keo-pi ha-na djou-sé-yo` |
| **직원이 하는 말** | 우유 넣을까요? | `ou-you neo-eul-kka-yo` |
| **학습자가 하는 말** | 아니요, 괜찮아요. | `a-ni-yo, kouèn-tchan-a-yo.` |
| **학습자가 하는 말** | 얼마예요? | `eol-ma-yé-yo` |
| **직원이 하는 말** | 삼천 원이에요. | `sam-tcheon ouon-i-é-yo` |

---

**1.** 전체가 실제 카페 대화처럼 들리나요? 아니라면 어디가 어색한가요?

> 

**2.** 학습자가 먼저 「안녕하세요!」라고 인사합니다. 들어오는 손님으로서 자연스러운가요?

> 

**3.** 「커피 하나 주세요.」 — 이렇게 주문하시겠어요? 아니라면 어떻게 말하시겠어요?

> 

**4.** **가장 중요한 질문입니다.** 「아니요, 괜찮아요.」가 「우유 넣을까요?」에 대한 완전한 대답으로 단독으로 나옵니다. 따로 떼어 놓아도 여전히 공손하게 들리나요, 아니면 퉁명스러운가요?

> 

**5.** 그다음에 「얼마예요?」를 별도 문장으로 말합니다. 거절한 직후에 자연스러운가요?

> 

**6.** 직원의 말은 「안녕하세요. 뭐 드릴까요?」 「우유 넣을까요?」 「삼천 원이에요.」입니다. 직원이 실제로 이렇게 말하나요?

> 

**7.** 구식이거나 지역적이거나, 본인이라면 절대 쓰지 않을 표현이 있나요?

> 

**8.** 특히 「괜찮아요.」를 봐 주세요. 사전에는 '괜찮다'는 뜻으로만 올라 있는데, 우유를 거절하는 대답으로 쓰였을 때 공손하게 들리나요? 「아니요, 괜찮습니다.」가 더 자연스러울까요?

> 

**9.** 선택 사항이며 프랑스어를 읽으실 수 있는 경우에만: 프랑스어 사용자가 「커피 하나 주세요.」에 가깝게 발음하려고 「keo-pi ha-na djou-sé-yo」를 읽습니다. 비슷한가요?

>
