# Melunga — 母语者校对，中文第一课

这是一个语言应用的第一课。学习者是一位零基础的法语母语学习者。以下内容已经在应用里了；我们只需要知道它听起来是否地道。每题一行即可，五到十分钟。

## 场景

| | | 给法语读者的发音近似 |
|---|---|---|
| **学习者说** | 你好！ | `ni hao !` |
| **服务员说** | 你好。您要什么？ | `ni hao. ninn yao cheun-meu ?` |
| **学习者说** | 请给我一杯咖啡。 | `tching gueï ouo i peï ka-feï` |
| **服务员说** | 加牛奶吗？ | `tia niou-naï ma ?` |
| **学习者说** | 不用，谢谢。 | `pou-yong, sié-sié.` |
| **学习者说** | 多少钱？ | `douo-chao tchyèn ?` |
| **服务员说** | 二十块。 | `eur-chr kouaï` |

---

**1.** 整段对话像真实的咖啡馆吗？如果不像，哪里不对？

> 

**2.** 学习者先说「你好！」打招呼。顾客进门这样说自然吗？

> 

**3.** 「请给我一杯咖啡。」——你会这样点单吗？如果不会，你会怎么说？

> 

**4.** **关键问题。** 「不用，谢谢。」单独出现，作为对「加牛奶吗？」的完整回答。单独说出来，还礼貌吗？会不会显得生硬？

> 

**5.** 接着单独说「多少钱？」。刚拒绝完就这样问，自然吗？

> 

**6.** 服务员的话是「你好。您要什么？」「加牛奶吗？」「二十块。」。服务员真的会这样说吗？

> 

**7.** 有没有听起来过时、带地方色彩、或者你根本不会说的地方？

> 

**8.** 另外请特别看「不用，谢谢。」：作为拒绝加奶的完整回答，语气合适吗？还是「不用了，谢谢」更自然？

> 

**9.** 可选，如果你懂法语：法语读者会把「tching gueï ouo i peï ka-feï」读出来近似「请给我一杯咖啡。」。接近吗？
