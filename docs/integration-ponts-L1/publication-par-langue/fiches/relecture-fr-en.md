# Melunga — native check, first English lesson

This is the very first lesson of a language app. The learner is a French speaker who is an absolute beginner in English. Everything below already exists in the app; we only need to know whether it sounds right to you. Please answer in one line each — five to ten minutes is plenty.

## The scene

| | | French-reader pronunciation guide |
|---|---|---|
| **LEARNER SAYS** | Hello! | `hè-LÔ` |
| **STAFF SAYS** | Hello. What would you like? | `hè-LÔ. ouot would you LAÏK` |
| **LEARNER SAYS** | One coffee, please. | `OUANN KO-fi, PLIZ` |
| **STAFF SAYS** | With milk? | `ouiz MILK` |
| **LEARNER SAYS** | No, thanks. | `NÔ, THANKS.` |
| **LEARNER SAYS** | How much is it? | `HAÔ MEUTCH iz it` |
| **STAFF SAYS** | Two pounds. | `TOU PAÔNDZ` |

---

**1.** Does the whole exchange sound like a real café in your country? If not, what feels off?

> 

**2.** The learner greets first with « Hello! ». Natural for a customer walking in?

> 

**3.** « One coffee, please. » — is this how you would order? If not, what would you say?

> 

**4.** **The key question.** « No, thanks. » is shown on its own, as a complete reply to « With milk? ». On its own, does it still sound polite — not curt?

> 

**5.** « How much is it? » is then said as a separate sentence. Natural right after refusing?

> 

**6.** The staff lines are « Hello. What would you like? », « With milk? », « Two pounds. ». Would staff really say these?

> 

**7.** Anything here that sounds dated, regional, or that you would simply never say?

> 

**8.** Optional, only if you read French: a French speaker reads « OUANN KO-fi, PLIZ » aloud to approximate « One coffee, please. ». Does that get close?
