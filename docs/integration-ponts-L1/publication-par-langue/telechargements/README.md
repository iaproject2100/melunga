# Fiches L1 à télécharger et à faire remplir

Les sept questionnaires de Claude sont proposés en PDF et en Word modifiable, sans changer les questions, les phrases ou les aides phonétiques.

- `fiches-L1-sept-langues.pdf` : les sept fiches réunies, pour consultation ou impression.
- `fiches-L1-a-remplir.zip` : une version Word et une version PDF séparées pour chaque langue.

Envoyer à chaque relecteur uniquement la fiche de sa langue. Le fichier `relecture-zh-fr` concerne le français enseigné à un sinophone ; il est à faire remplir par un francophone.

Les réponses restent vierges. Ces documents ne constituent pas une validation native ni un accord de publication. Aucune scène n’est activée et le site reste inchangé.

Les sources Markdown exactes se trouvent dans [../fiches/](../fiches/). Les contrôles de copie et de conversion figurent dans `verification-formats.json`.
