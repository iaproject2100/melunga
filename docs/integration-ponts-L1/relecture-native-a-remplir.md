# Relecture native des sept scènes L1 — à remplir

**Statut : en attente dans les sept langues. Aucune validation native n’est acquise.**

Copie de travail des 49 répliques de `melunga_deploy/content/l1-cafe.json`, reprises dans leur ordre exact. Source éditoriale : `30e7d40` ; intégration relue : `b0171bd`. Le refus et la demande de prix sont désormais deux répliques successives du client : relire et jouer cette forme détachée.

`study` est la phrase étudiée ; `native` est son sens dans la langue du lecteur ; `phon` est l’aide phonétique existante et `reading` la lecture existante, seulement lorsqu’elle est présente dans la source. A = apprenant/client ; B = serveur, à comprendre. L’ordre numéroté est celui de la scène, sans nouvelle phrase ni nouvelle phonétique.

Pour **zh→fr**, le lecteur est sinophone : `study` est en français, `native` en chinois et `phon` contient ses repères de prononciation pour ce lecteur. Les rôles source sont `顾客` (client) et `服务员` (serveur). Il ne faut pas supposer une traduction française dans `native`. Dans les six autres couples, le lecteur est francophone et `native` est en français.

Chaque section doit être remplie par le relecteur de la langue étudiée. Le naturel oral et l’intonation nécessitent d’écouter ou de jouer l’échange ; une vérification du texte seul ne les valide pas. Consigner une proposition dans les notes, sans remplacer les copies ci-dessous. Toute modification de texte, de sens, de phonétique ou de lecture exige un lot source séparé, vérifié puis relu.
