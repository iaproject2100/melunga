# Convention espagnole : la jota s'écrit `r`

**Décision de Kartech (26 octobre 2026).** La jota (*j*, et *g* devant *e* ou *i*) s'écrit `r` partout, comme dans le L1 : `mé-ROR`, `LÉ-ros`. Les graphies `kh` et `rh` sont remplacées par `r`, et `KH` et `RH` par `R`.

**110 aides entières** sont concernées. Le registre est [`registre-jota.json`](registre-jota.json). Pour chaque aide, j'ai vérifié que le nombre de `kh` et de `rh` ne dépasse pas le nombre de jotas de l'étude. Aucun bloc du registre de contenu n'écrit `kh` ou `rh` : il n'y a donc pas de chaînage à faire.

Référence : `13f42b5`. Rien n'est fusionné dans `main` ni publié sur melunga.com.
