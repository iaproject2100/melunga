# Ordre proposé pour l’italien et le coréen

Le fichier `editorial-ko-it.json` décrit les **238 unités** des deux couples actifs : 120 en français → italien et 118 en français → coréen. Leurs **952 variantes entières** ont été examinées ; aucune n’est supprimée ou réécrite. Les 20 empreintes de fichiers sources sont conservées dans le plan. Ce sont des décisions éditoriales candidates, sans publication ni validation native.

Les unités L1 restent toutes en L1. Les déplacements concernent uniquement les niveaux payants L2–L10 ; ni les niveaux sources, ni le catalogue, ni l’offre gratuite, ni les droits ne sont modifiés.

## Premier remplacement : portée exacte

Les **68 couples de variantes** retenus pour un premier remplacement gardent un cadre source strict et une seule variable visée. Les deux variantes choisies viennent en premier dans `variantOrder`, puis les deux autres restent disponibles. Le contrôle littéral `préfixe + slot source + suffixe` est respecté ; les formes entières et leurs aides restent l’autorité.

La vérification linguistique a écarté des changements de particule masqués. Par exemple, le premier choix de lieu coréen conserve `이` avec les variantes 0 et 3 de `L1-fr-ko-05` ; le premier choix de matière conserve `를` avec les variantes 0 et 3 de `L4-fr-ko-07`. Aucune règle de particule n’est déduite en collant les morceaux.

Les autres groupes sont déclarés `whole-expression`. Leur présence ne certifie aucune substitution commune : chaque expression doit être comprise et imitée séparément. Les variantes de registre, de personne, de temps, de compteur ou de portée de négation sont signalées dans `gaps` quand elles empêchent une telle lecture.

## Limites conservées

Les dépendances sont strictement antérieures dans le nouvel ordre et appartiennent au même couple de langues. Elles indiquent des reprises prévues, pas des acquis observés, ni la préparation exhaustive des mots d’une unité nouvelle. Les dialogues, leurs répliques reçues et leur naturel restent un chantier distinct de cet ordre d’unités.

Le registre historique de `L1-fr-ko-03` est signalé sans retoucher ses traductions. Aucune phonétique, lecture, ponctuation ou phrase étudiée n’a été corrigée, harmonisée ou recomposée. Aucun verdict natif n’est attribué.
