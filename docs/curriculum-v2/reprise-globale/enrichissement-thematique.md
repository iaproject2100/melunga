# Enrichissement thématique : ce qui existe et ce qui manque

Douze situations précises, vérifiées dans les sept couples, sans rédiger de phrase étrangère ni toucher aux phonétiques. Il ne s’agit pas de douze thèmes entièrement nouveaux : ils croisent les trente familles déjà présentes. Les inspirations de méthode viennent des [six sources officielles lues](concurrents.md) ; les phrases viennent uniquement de Melunga.

Base de travail : `7d24556`. Carte documentaire uniquement ; aucun changement produit, aucune publication. Le [JSON associé](enrichissement-thematique.json) contient les références, les empreintes des sources, les copies exactes et les limites par couple.

Bilan : **84 cas** = 12 situations × 7 couples ; **23 échanges existants**, **8 échanges voisins**, **46 ensembles de phrases partielles**, **7 manques ciblés**. Ce ne sont pas 84 leçons prêtes : « échange existant » décrit la présence d’un dialogue, pas sa préparation pédagogique ni son autorisation de publication.

Les niveaux proposés indiquent une réussite visée dans le cadre commun. Ils ne déplacent aucune carte et ne prouvent aucun prérequis. Exemple : prévenir d’un retard est une tâche simple, mais une forme chinoise avec probabilité et délai peut ajouter plusieurs opérations ; son niveau source L8 n’est ni une raison de la conserver tard ni une raison de la descendre sans préparation.

Le champ de prononciation est choisi selon le lecteur : `pf` en anglais, espagnol, italien, japonais et coréen pour francophones ; `phf` en chinois pour francophones ; `phon` en français pour sinophones. Toutes les aides présentes sur les énoncés sélectionnés sont conservées au caractère près.
