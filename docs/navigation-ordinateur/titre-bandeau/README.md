# Bandeau du titre validé par Kartech

Kartech a choisi la proposition 2 de `propositions-titre.html`. Le titre du thème dans les fiches reçoit le fond légèrement teinté et le liseré de 4 px dans la couleur de l'ambiance. Les coins droits sont arrondis ; le texte garde sa taille, sa graisse et sa couleur publiées. Les marges intérieures passent de 12 × 14 px à 8 × 10 px sur mobile pour conserver la place de la fiche.

Le produit ne change que les deux règles CSS du titre et le cache CSS v22 dans les deux entrées HTML. Le JS, les données, le logo, les langues, le rail, la progression, les prix, les droits et le catalogue classique restent strictement ceux de `e337f6f`.

Le groupe existant de contrôle du titre vérifie les trois ambiances, les premières et longues fiches réelles, ainsi que l'absence de défilement, de texte tronqué et de chevauchement sur ordinateur et mobile simulé. Son exécution est ciblée avec le contrôle de conservation des sources ; les autres groupes ne sont pas présentés comme rejoués. Les empreintes courantes sont actualisées dans quatre tests existants, sans changer leurs couches de projection historiques.

Les captures sont des rendus locaux Chromium avec tailles d'écran simulées. Aucun téléphone physique, compte réel ou audio joué n'est revendiqué.
